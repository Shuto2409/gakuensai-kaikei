① Firebase プロジェクトを作成（無料）

console.firebase.google.com を開く → Googleアカウントでログイン →「プロジェクトを追加」→ 名前を入力 → Google Analytics はオフでOK

② Realtime Database を有効化

左メニュー「構築」→「Realtime Database」→「データベースを作成」→ リージョン asia-southeast1 →「テストモードで開始」→「有効にする」

③ 設定コードをコピーして貼り付け

「⚙️ プロジェクトの設定」→「マイアプリ」→「</>」→ アプリ登録 → firebaseConfig = { ... } の { } ごとコピー

Firebaseは月100万回まで無料です
